nano 快捷键概览
=====================================

# 编辑器快捷键及其功能

## 文件处理

| 快捷键 | 描述 |
|:--|:--|
| Ctrl+S | 保存当前文件 |
| Ctrl+O | 另存为（"Save as"） |
| Ctrl+R | 将文件插入到当前文件 |
| Ctrl+X | 关闭缓冲区，退出 nano |

## 编辑

| 快捷键 | 描述 |
|:--|:--|
| Ctrl+K | 剪切当前行到剪切缓冲区 |
| Alt+6 | 复制当前行到剪切缓冲区 |
| Ctrl+U | 粘贴剪切缓冲区的内容 |
| Alt+T | 剪切直到缓冲区末尾 |
| Ctrl+\] | 补全当前单词 |
| Alt+3 | 注释/取消注释行或区域 |
| Alt+U | 撤销上一个操作 |
| Alt+E | 重做上一个撤销的操作 |

## 搜索与替换

| 快捷键 | 描述 |
|:--|:--|
| Ctrl+Q | 开始向后搜索 |
| Ctrl+W | 开始向前搜索 |
| Alt+Q | 查找上一个匹配项 |
| Alt+W | 查找下一个匹配项 |
| Alt+R | 开始替换会话 |

## 删除

| 快捷键 | 描述 |
|:--|:--|
| Ctrl+H | 删除光标前的字符 |
| Ctrl+D | 删除光标处的字符 |
| Alt+Bsp | 向左删除一个单词 |
| Ctrl+Del | 向右删除一个单词 |
| Alt+Del | 删除当前行 |

## 操作

| 快捷键 | 描述 |
|:--|:--|
| Ctrl+T | 执行命令 |
| Ctrl+J | 对齐段落或区域 |
| Alt+J | 对齐整个缓冲区 |
| Alt+B | 运行语法检查 |
| Alt+F | 运行格式化/修复/整理工具 |
| Alt+: | 开始/停止录制宏 |
| Alt+; | 回放宏 |

## 光标移动

| 快捷键 | 描述 |
|:--|:--|
| Ctrl+B | 向后移动一个字符 |
| Ctrl+F | 向前移动一个字符 |
| Ctrl+**←** | 向后移动一个单词 |
| Ctrl+**→** | 向前移动一个单词 |
| Ctrl+A | 移至行首 |
| Ctrl+E | 移至行尾 |
| Ctrl+P | 上移一行 |
| Ctrl+N | 下移一行 |
| Ctrl+**↑** | 移至上一个代码块 |
| Ctrl+**↓** | 移至下一个代码块 |
| Ctrl+Y | 上翻一页 |
| Ctrl+V | 下翻一页 |
| Alt+\\ | 移至缓冲区顶部 |
| Alt+/ | 移至缓冲区末尾 |

## 特殊移动

| 快捷键 | 描述 |
|:--|:--|
| Alt+G | 跳转到指定行 |
| Alt+\] | 跳转到匹配的括号 |
| Alt+**↑** | 向上滚动视口 |
| Alt+**↓** | 向下滚动视口 |
| Alt+< | 切换到上一个缓冲区 |
| Alt+> | 切换到下一个缓冲区 |

## 信息

| 快捷键 | 描述 |
|:--|:--|
| Ctrl+C | 报告光标位置 |
| Alt+D | 报告行数/单词数/字符数统计 |
| Ctrl+G | 显示帮助文本 |

## 其他

| 快捷键 | 描述 |
|:--|:--|
| Alt+A | 开启/关闭标记 |
| Tab | 缩进标记区域 |
| Shift+Tab | 取消缩进标记区域 |
| Alt+V | 逐字输入下一个按键 |
| Alt+N | 开启/关闭行号 |
| Alt+P | 开启/关闭可见空白字符 |
| Alt+X | 隐藏或显示帮助行 |
| Ctrl+L | 刷新屏幕 |
